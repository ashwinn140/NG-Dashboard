How this view is calculated

Different fields use AND; multiple values in one field use OR. An organization selected in Any role is counted once per source record, even when it appears in several roles.

Operations and finance are filtered independently using their own source attributes and dates. The detail table combines unique matched records; a drawer shows each source separately. Select Matched only to require both sources to meet the relationship filters.

Origin Agent and Destination Agent use explicit source fields or a unique register match when the job report omits that field. Generic Booking Through, Overseas Agent and Agent Name are not substituted for these roles. Unavailable fields remain blank and will not match a named filter.

Organization selectors use exact source names (with whitespace cleaned), not a verified cross-company organization-code master. Similar names are not merged automatically. Clearance and road financial records may be present without operational registers.

Finance visibility, company and LOB permissions follow your dashboard account. CSV exports use the same filtered records and permissions. Saved views are private to your login. Financial totals use Job Date; activity uses Shipment Date. Missing financial values appear as —, not zero.
